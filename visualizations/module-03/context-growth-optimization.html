    Move 1 · Select

    Stable context first, volatile last. If you typed it three times, it belongs one layer up.

      Technique spotlight · where you put the critical rule

      Models use the start and end of a long input best

      “Lost in the middle” (Liu et al., TACL 2024). Put the non-negotiable constraint first or last, and restate it in your prompt. Instructions files load first, which is one reason Layer helps.

      5 · Take it back to your repo

      Six habits that keep a long chat lean

      Start a new chat when…

      • the task changes
      • the model repeats old mistakes
      • a plan is written to a file — the file carries the decisions, not the chat

      Read the stoplight

      0–60%Comfortable — carry on
      60–85%Trim now — detach files, trim logs
      85%+Compact or restart

      A course rule of thumb, not a product setting.

      Say why, or detach

      If you can’t say why a file is attached, detach it. Select a range, not a file; #codebase is a search — check what it found.

      One layer up

      Typed the same instruction three times? It belongs one layer up. An instruction for one task does not belong in an always-on file — it costs tokens on every request.

      Hand off, don’t drag

      Keep Goal / Decided / Done / Next. Paste the failing lines plus 5 around them, never the whole log.

      Tokens are credits

      Per the deck, Copilot is billed in AI credits consumed by token usage (since June 2026). Bloated context costs credits on every request and still lowers answer quality. Module 11 turns this into measured ROI.
